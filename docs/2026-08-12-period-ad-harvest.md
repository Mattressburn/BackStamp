# Period-ad harvest, run 1 (2026-08-12)

Public-domain evidence for Pyrex promotional pieces. Sources: Chronicling America
(via the current loc.gov JSON API; the documented chroniclingamerica.loc.gov API is
dead, see Method notes) and Internet Archive. ~50 HTTP requests, all JSON endpoints,
spaced ~1s.

Confidence key: **high** = name AND model number legible in the source;
**medium** = name legible, number missing or garbled; **low** = suggestive only.
Newspaper ads almost never print model numbers, so newspaper finds cap at medium
even when name, size, price and date are all clean; the IA trade catalogs are where
the model numbers live.

### E. Internet Archive trade catalogs — the model-number sources (HIGH confidence rows)

Four scanned Corning consumer/dealer catalogs found, all with OCR text:

1. **pyrex-cookware-1969** ("Pyrex Cookware 1969") — a dealer price list with model
   numbers, case packs, and per-piece prices. Substantiates with model numbers:
   - Dot bowls: "1½ Pt. Orange Dot Bowl / 1½ Qt. Yellow Dot Bowl / 2½ Qt. Blue Dot
     Bowl", numbers in the 401/402/40x-20 range (No. 401-20 legible). **high**
   - Butterprint on 470-series: "Bowl 472-B 1.10 ... Butterprint only" with covers
     470-C $0.45, "Turquoise Daisy 470-C-39 $0.90". **high**
   - Verde 4-qt bowl No. 404-16-D, $1.75 each. **high**
   - Decoration color chart: forms 043, 045, 063, 401, 402... with decoration
     suffixes (-19/-16 Verde, -39 Daisy, -20 Dot, -11). This is the key that decodes
     hyphenated model numbers on 1964+ promo/standard pieces. **high**
2. **corning-pyrex-ware-1972** ("Corning Pyrex Ware 1972") — Horizon Blue No. 300-41
   3-pc mixing bowl set $3.95/set; Friendship No. 300-45 3-pc set $3.95 and
   No. 400-45 4-pc set; "10-OZ. CASSEROLE—HORIZON BLUE" at $11.88/case of 12;
   Early American, Daisy-39, Verde-16 columns. **high**
3. **pyrex-flameware-1955** — one-sheet, prices above. **medium**
4. **CorningPyrex1927** ("Pyrex Ware", 1927) — known already, not mined this run.

## What paid off, what was noise

**Paid off**
- `pyrex+candle+warmer` — the single best generic query. Promos shipped with
  warmers, so it surfaces promo ads and skips recipe columns. Found the Corning
  national ad and both hardware-store line ads.
- Promo-name queries where the name is distinctive: zodiac, bluebird, snowflake,
  scroll+casserole, hostess+casserole, snack+server, chip+dip.
- **Follow the repeat advertisers, not the search term.** Small-town hardware
  stores ran the full promo line every November-December. Best papers:
  Peninsula Enterprise (Accomac, Va.; sn94060041), Milford Chronicle (Del.;
  sn87062224), Bluffton News (Ohio; sn87076554), Hardin Tribune-Herald (Mont.;
  sn86075229), and Evening Star (DC; sn83045462) Nov/Dec department-store pages.
  Next run: page through those papers' Nov 1-Dec 20 issues for 1956-1963 directly.
- IA `advancedsearch` on `title:(pyrex) AND mediatype:texts` — found all four
  catalogs in one query.

**Noise**
- Flower/fruit promo names collide with garden and grocery ads: daisy (also Daisy
  BB guns), tulip, poinsettia, grapes. Pair them with casserole/bowl/cradle next
  time, e.g. `pyrex+poinsettia+casserole`.
- `pyrex+hostess+casserole` at 58 hits is mostly recipe columns; only dealer-ad
  pages matter.

**Method notes (things that changed or broke)**
- The documented API endpoint `chroniclingamerica.loc.gov/search/pages/results/`
  is DEAD: 308-redirects to www.loc.gov and 404s. Working endpoint:
  `https://www.loc.gov/collections/chronicling-america/?q=TERMS&dates=YYYY/YYYY&fo=json&c=N`.
- Search results sometimes carry an OCR snippet in `results[].description[0]`;
  when absent, fetch `RESOURCE_URL&fo=json` and follow
  `.resources[0].fulltext_file` (tile.loc.gov word-coordinates service, small JSON
  with `full_text`). The old `.../ocr.txt` path 403s.
- Column-interleaved OCR loses item names mid-list (the red/gold oval above); the
  page image would recover it (image URLs are in the resource JSON, not fetched
  this run).

## 1964+ coverage gap

Chronicling America's digitized runs used here effectively end at 1963 (public
domain window), so the 1964-1975 promos — the deep grails like the later Golden
promos, Empire Scroll's successors, and everything Horizon-era sold as a promo —
cannot be evidenced from CA at all. Explicitly a gap, not an absence of the pieces.
Partial fill found: the 1969 and 1972 IA dealer catalogs above carry model-number
tables for standard lines (Dot, Daisy, Verde, Horizon Blue, Friendship,
Butterprint) but catalogs list the standard line, not one-season promos. Next
lanes for 1964+: IA magazine scans (searched only cursorily this run) and any
state digital newspaper program with post-1963 runs.
